## Краткие теоретические сведения

Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной (CPython). Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (ровно 4 пробела) обязательны и служат для группировки блоков кода. Форматированные строковые литералы (f-строки) позволяют удобно вставлять выражения в строки. Например, выражение `f'{pi:.3f}'` форматирует вещественное число с точностью до трех знаков после запятой.

## Исходный код программы

**Задание:** Напишите скрипт, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить строго с помощью f-строк с округлением вещественной части до 4 знаков после запятой.

*Формула:* Энергия заряженного конденсатора: \(W = (C * U^2)/2 
*Значения:* \(C = 4.7e-5\), \(U = 220\).

```python
C = float(input("Величина C: "))
U = float(input("Величина U: "))
print(f"W = {round ((C*U**2)/2, 4)}"
```
